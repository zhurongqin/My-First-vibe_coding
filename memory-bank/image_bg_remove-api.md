通用抠图接口调用文档（外部开发人员使用）
一、文档概述
本文档提供通用抠图接口的详细调用说明，该接口支持 File 文件上传 和 Base64 编码输入 两种方式，自带接口限流，可用于小程序、Web 应用、后端服务等各类场景的图片抠图需求。接口返回标准化 JSON 结果，同时支持图片 URL 和 Base64 格式输出，方便调用方直接使用。
二、基础信息
项目	详情
接口服务地址	http://{你的服务器 IP}:[端口]（默认：http://115.159.43.168:5000）
请求协议	HTTP/HTTPS（生产环境建议配置 HTTPS）
支持请求方式	POST（文件 / Base64 接口）、GET（图片访问接口）
字符编码	UTF-8
限流规则	单个 IP 每分钟最多调用 60 次（可自定义调整）
支持图片格式	jpg、jpeg、png、bmp、webp
三、接口列表
1. 文件上传抠图接口（兼容旧版本）
接口信息
接口路径：/api/remove-bg/file
请求方式：POST
请求格式：multipart/form-data
接口描述：接收本地图片文件上传，返回抠图结果
请求参数
参数名	必选	类型	描述
file	是	UploadFile	待抠图的图片文件（单文件）
返回结果
字段名	类型	描述
code	int	状态码（0 = 成功，非 0 = 失败）
msg	string	提示信息
image_url	string	抠图结果图片访问 URL（可直接预览 / 下载）
image_path	string	服务器端抠图文件存储路径
unique_name	string	服务器端抠图文件唯一标识名称
错误码说明
状态码	描述
0	抠图成功
400	请求参数错误 / 文件格式不支持
429	接口调用频率超限（限流触发）
500	服务器内部错误

2. Base64 编码抠图接口（通用调用）
接口信息
接口路径：/api/remove-bg/base64
请求方式：POST
请求格式：application/json
接口描述：接收 Base64 编码图片字符串，返回抠图结果（支持带 / 不带 data:image 前缀）
请求参数
参数名	必选	类型	描述
base64_str	是	string	Base64 图片编码（支持：带前缀 / 纯编码字符串）
返回结果
字段名	类型	描述
code	int	状态码（0 = 成功，非 0 = 失败）
msg	string	提示信息
image_url	string	抠图结果图片访问 URL（可直接预览 / 下载）
image_path	string	服务器端抠图文件存储路径
unique_name	string	服务器端抠图文件唯一标识名称
image_base64	string	抠图结果 Base64 编码（带 data:image 前缀，可直接渲染）
错误码说明
同「文件上传抠图接口」错误码

3. 抠图结果图片访问接口
接口信息
接口路径：/result/{filename}
请求方式：GET
接口描述：通过唯一文件名访问抠图后的图片文件，支持直接预览和下载
请求参数
参数名	必选	类型	描述
filename	是	string	抠图文件的唯一名称（来自接口返回的 unique_name）
返回结果
成功：返回图片二进制流（可直接在浏览器预览、下载）
失败：返回 JSON 格式错误信息（code=1，msg="图片不存在"）
调用示例
浏览器直接访问：http://115.159.43.168:5000/result/xxx-xxx-xxx.jpeg
curl 下载：curl -O http://115.159.43.168:5000/result/xxx-xxx-xxx.jpeg
通用注意事项
接口限流：单个 IP 每分钟最多调用 60 次，超出限制会返回 429 状态码，建议调用方添加重试机制（间隔 1 分钟以上）；
图片大小：建议单张图片不超过 10MB，过大图片可能导致请求超时；
Base64 编码：若调用方传递的 Base64 字符串包含换行符，请先去除后再请求；
HTTPS 配置：生产环境建议配置 SSL 证书，使用 https:// 协议调用，提高安全性；
超时设置：调用方建议设置请求超时时间（推荐 30 秒），避免因服务器处理缓慢导致请求挂起。
